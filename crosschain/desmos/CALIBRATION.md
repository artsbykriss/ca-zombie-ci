**Target:** Desmos mainnet `desmos-mainnet` — app **v7.1.1**, wasmvm **v1.5.3** →
cosmwasm-vm 1.5.6 → **Wasmer 4.2.2** (Singlepass) / corosensei 0.1.3, Cosmos SDK
**v0.47.10** (Desmos fork `desmos-labs/cosmos-sdk v0.47.10-desmos`).
**Engine:** **bit-identical to the verified PoC** (wasmer-4.2.2 / singlepass-4.2.2 /
corosensei-0.1.3 in both wasmvm 1.5.3 and 1.5.5) ⇒ the verified guests and the drift
*stride* are engine-determined and carry over.

**Scope:** read-only static analysis + **local in-process** harness runs. No chain
interaction, keys, signing, deployment, or broadcast. Heavy work ran on GitHub Actions
(`artsbykriss/ca-zombie-ci`, branch `crosschain`) via `bash ci/ci-run.sh crosschain`.
The downstream cash-out/exit is out of scope.

**Ground truth:** `ci/CROSS-CHAIN-FEASIBILITY.md` §3.2/§3.3/§6; the verified PoC
`artsbykriss/kimi-cwa006` `docs/TECHNICAL-RECORD.md` §0; `archway/live/LIVE-BROADCAST-PLAN.md` §2.

### 2.2 `runtime.g0` / `runtime.m0` derivation (stripped binary)

The pclntab `rt0_go` (`0x46f2e0`) is **mis-delimited** (the Archway port's known caveat).
The real entry is the pointer the ELF entry stub passes in `%rdi` — **`0x4bdca0`**. In that
region, by the Archway method, the first `lea …,%rdi`/`%rcx` to `.data`/`.bss`
(`0x4bdcd8: lea 0x5950b01(%rip),%rdi # 0x5e0e7e0`) is **`runtime.g0 = 0x5e0e7e0`**, and the
nearby `lea …,%rdi/%rax # 0x5e0f828` is the **`runtime.m0 = 0x5e0f828`** candidate.
Full region: `ci-out/desmos/desmos_rt0go.txt`; filtered: `desmos_g0_candidates.txt`.
*(For the harness builds these are taken authoritatively from `nm`, §3.)*

### 5.3 The Go-1.21.13 boundary (localised)

The failure is at the **crossing / landing phase** — the drift does **not** place the pivot on
the holder return slot. Localisation:

- **Holder return slot = `top-0x308`, confirmed identical** to the PoC on the Desmos builds:
  `-scanchain` shows `-0x308:exec(libwasmvm)+0x5c4c3` and `-0x310:fiber+0xffec0` (saved RBP)
  in the suspended fibre (`desmos_g121_rsweep_recal.json` `chain_lines`). **The slot is not
  the difference.**
- **Chain / g0 / ABI0 are correct** — all from `nm`; the identical code path lands on Go 1.23.5.
- **Exits** on the Go-1.21.13 build: **`2` (`morestack on g0`, dominant)** and **`139`
  (SIGSEGV)**, with many phases exiting **`0` (clean → no crossing at all)**; **no `M4BANK`**.
  The recorded `RIP`s are JIT / libwasmvm addresses (`0x…bdb`, `0x…0e7`), i.e. the chain
  **never runs**.
- **Swept and failed:** 128 call-phases `--offset 0,2,…,510` (0/256); 256 holder-frame shapes
  `--warmups {3,4} × --frame32 {0..3} × --dummy {0..15} × --offset {278,234}` (0/512).

**Unexplored (the remaining search space):**
1. **`--iters` (reach).** All sweeps held `--iters 66283` (≈1 fibre ≈ 65814 iterations). If,
   for Go 1.21.13, the **trigger fibre is >1 fibre away from the holder** (the `-scanchain`
   dump shows the pool has adjacent fibres but does not prove the trigger is directly above the
   holder), the drift **stops short**. Sweeping `--iters ∈ {66283, 132566, 198849, 265132,
   331415}` is now wired into `ci/run.sh` Phase 6 and is the **first thing to try**.
2. **Warm-up count** beyond `{3,4}` (pool priming/depth, not just parity) — `ci/run.sh` now
   sweeps `--warmups 0..12`.
3. **`--staged`** (holder frame size) and **`--spacing`** (call stride).
4. A **direct measurement of the trigger↔holder fibre adjacency** for Go 1.21.13 (which
   fibre holds which contract), which the current `-scanchain` dump does not disambiguate.

**Boundary statement.** On the **exact Desmos Go 1.21.13 / SDK 0.47.10 / wasmvm 1.5.3**
harness the native control transfer **does not land** with the PoC geometry, and the swept
phase/frame space is exhausted without a hit. The engine, guests, terminal and slot are all
correct; the open item is the **Go-1.21.13 crossing/reach**, with `--iters` the primary
untested axis. **No live action is recommended.**

## 6. Per-prerequisite status in the Desmos shape (Task 4)

### 6.1 ① The read / pointer primitive — **OPEN (strictly smaller)**

SDK 0.47.10's bank keeper takes `sdk.Context` **by value**, so there is **no runtime-created
`go:itab.Context,context.Context`**. What remains is a **strictly smaller** read than
Archway's: the **live `sdk.Context` bytes (~0.5 KB, by value)** plus a **`*BaseKeeper`**
pointer. **Boundary:** ≥ 1 leaked host pointer; no arbitrary-read exists.

### 6.2 ② The multi-argument invocation — **OPEN (unchanged)**

`runtime.cgocallback` invokes `fn(frame)` as an ABIInternal **`func(unsafe.Pointer)`** (one
arg). `MintCoins(ctx sdk.Context, name string, amt Coins)` needs the receiver + the ~0.5 KB
`ctx` **by value** + `string` + `Coins`. `cgocallback` alone is insufficient. The wasmvm
callbacks (`cSet`, `cQueryExternal`) *are* C-ABI multi-arg-callable (**Option D**) but reach
only the **contract KV / queries**. Remaining: **Option E** or a **JOP arg-load gadget**.

### 6.3 ③ The clean-commit continuation — **OPEN (unchanged)**

The nested query runs in `QueryHandler.Query`, which does `subCtx, _ := q.Ctx.WithGasMeter(…)
.CacheContext()` and **discards** it (source-verified in wasmd v0.32.0 / v0.45.0 / v0.51.0).
A committing mint must write through the **outer** `QueryHandler.Ctx` and return cleanly.

## 7. Remaining work (dependency order)

1. **Go-1.21.13 crossing/reach** (§5.3) — re-sweep with **`--iters` > 66283** (first), then
   `--warmups 0..12`, `--staged`, `--spacing`; and measure the trigger↔holder fibre adjacency
   for Go 1.21.13. *(Note the live node reports `go1.21.13`; the release asset is `go1.20.14`,
   which **does** land weakly — so the deployed toolchain should be confirmed before this
   target is written off.)*
2. **M1 — a read / pointer-leak primitive through `desmosd`'s real wasmvm 1.5.3.** Absent;
   the Desmos target objects are the **live `sdk.Context` bytes + `*BaseKeeper`** (no itab).
3. **Context/keeper staging** — borrow the **outer** `QueryHandler.Ctx` (stage the ~0.5 KB
   `sdk.Context` by value) and a live `*BaseKeeper`.
4. **Invocation (②)** — **Option E** or a **JOP arg-load gadget**.
5. **Clean-commit continuation (③)** — drop the terminal `UD2`; use the outer ctx + clean return.
6. **Live determinism (④)** — Desmos has **16 bonded validators**; the crossing is
   probabilistic, so live it is first a **halt vector**, then a mint.
